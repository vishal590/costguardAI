## Initial Submission Checklist

**Deadline:** January 21, 2026 ⚠️

### Pre-Submission Setup
- [ ] AWS Builder Center profile created and completed
- [ ] Joined 10,000 AIdeas Competition official space
- [ ] AWS account created (Free Tier)
- [ ] Kiro downloaded (if planning to use)

### Eligibility Verification (MANDATORY - See [terms.md](../competition/terms.md))
- [ ] 18 years or older
- [ ] Valid AWS Builder ID
- [ ] Reside in eligible country (NOT in excluded countries list)
- [ ] Not an AWS employee or family member
- [ ] Only submitting one idea
- [ ] **Reviewed Terms and Conditions** ⚠️

### Submission Content (MANDATORY Requirements)
- [ ] Application idea clearly described (Project Description)
- [ ] **Detailed documentation of Kiro implementation** ⚠️ **REQUIRED**
- [ ] Value proposition explained (why it matters)
- [ ] Market impact or potential described
- [ ] How you plan to build it explained
- [ ] AWS Free Tier services listed
- [ ] Rationale for each AWS service provided
- [ ] Submission is focused and compelling
- [ ] **Compliance with Terms and Conditions verified** ⚠️

### Final Checks
- [ ] All submission fields completed
- [ ] Submission reviewed for clarity
- [ ] **Submission submitted before deadline (January 21, 2026 11:59pm PT)** ⚠️
- [ ] **Submitted early if possible** (AWS evaluates "first 10,000+ submissions received")
- [ ] Confirmation received

## Semi-Finalist Preparation Checklist

**If Selected:** Top 1,000 semi-finalists (announced February 11, 2026)

### Application Development
- [ ] Application built and functional
- [ ] Kiro used for at least portion of development
- [ ] Application stays within AWS Free Tier limits
- [ ] Application is original and unpublished
- [ ] Application tested and working

### Builder Center Article (Due: March 13, 2026)
- [ ] Article published on Builder Center
- [ ] Application overview included
- [ ] Why it matters explained
- [ ] AWS services used listed
- [ ] Justification for each AWS service provided
- [ ] Resource optimization strategies documented
- [ ] Expected running costs included
- [ ] Team name included
- [ ] Demo included (video/screenshots)

### Article Quality
- [ ] Article is clear and well-written
- [ ] All required sections included
- [ ] Demo is functional and demonstrates key features
- [ ] Article reviewed before submission
