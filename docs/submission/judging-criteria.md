## Judging Overview

All eligible entries received during the Initial Submission Period will be evaluated or judged (as applicable), and participants will be selected to proceed to the applicable round, based on the following criteria and processes.

## First-Round Finalists (Top 1,000)

**Evaluation Period:** January 21, 2026 9:00am PT to February 11, 2026 5:00pm PT

**Evaluation Method:** AWS using a combination of AI tools and human review

**Selection:** First 10,000+ Initial Submissions evaluated

**Criteria:**
- **Project Completeness (50%)**
  - All required submission elements included
  - Detailed Kiro implementation documentation
  - AWS services clearly identified
  - Market impact well-defined
- **Content Creativity (50%)**
  - Innovative approach
  - Creative problem-solving
  - Unique value proposition
  - Originality

**Result:** 1,000 First-Round Finalists selected

---

## Semi-Finalists (Top 300)

**Voting Period:** March 13, 2026 12:01am PT to March 19, 2026 11:59pm PT

**Evaluation Method:** AWS using community voting process held on AWS Builder Center

**Selection Criteria:**
- **Articles with the highest number of likes**
- Community engagement
- Article quality and clarity

**Result:** Top 300 Semi-Finalists announced March 20, 2026 9:00am PT

---

## Finalists (Top 50)

**Review Period:** March 20, 2026 9:00am PT to April 3, 2026 5:00pm PT

**Evaluation Method:** Panel of AWS experts and AWS Heroes

**Criteria:**
- **Technical Innovation (34%)**
  - Breakthrough technical implementation
  - Creative use of AWS services
  - Innovative AI/ML application
  - Kiro integration effectiveness
- **Implementation Quality (33%)**
  - Code quality
  - Architecture design
  - Best practices adherence
  - Free Tier optimization
- **Market Impact (33%)**
  - Real-world problem solving
  - Potential user impact
  - Scalability potential
  - Commercial viability

**Result:** 50 Finalists announced April 3, 2026 5:00pm PT

---

## Key Evaluation Points

### For Initial Submission
- **Project Completeness:** Ensure all required elements are included
- **Kiro Documentation:** Detailed documentation of Kiro implementation is required
- **Creativity:** Focus on innovative and creative approach
- **Clarity:** Clear and compelling presentation

### For Builder Center Article
- **Technical Depth:** Detailed technical architecture and implementation
- **Documentation:** Clear documentation of AWS services and Kiro usage
- **Demo Quality:** Effective demonstration of application
- **Engagement:** Community engagement (likes) is important for voting stages

### For Final Evaluation
- **Technical Innovation:** Breakthrough implementation
- **Quality:** High-quality code and architecture
- **Impact:** Real-world market impact
- **Scalability:** Global scalability potential
