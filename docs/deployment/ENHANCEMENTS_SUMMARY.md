## Search Methods

### 1. Error Message Search
**Best for:** Exact error from terminal  
**Location:** [Quick Issue Finder](./DEPLOYMENT_TROUBLESHOOTING.md#quick-issue-finder)  
**Example:** `AttributeError: ... 'SnsAction'` → Issue 4

### 2. Symptom Search
**Best for:** Describing problem  
**Location:** [Search by Symptom](./DOCUMENTATION_INDEX.md#-search-by-symptom)  
**Example:** "Can't delete cdk.out" → CDK Output Fix

### 3. Tag Search
**Best for:** Finding related content  
**Location:** [Search by Tag](./DOCUMENTATION_INDEX.md#️-search-by-tag)
**Example:** `phase-5` + `critical` → Python import error

### 4. Phase Search
**Best for:** Phase-specific info  
**Location:** [Search by Phase](./DOCUMENTATION_INDEX.md#-search-by-phase)  
**Example:** Phase 5 → Multi-account docs

### 5. Keyword Search
**Best for:** Full-text search  
**Location:** Any document header  
**Example:** "CloudWatch actions" → Phase 5 docs
