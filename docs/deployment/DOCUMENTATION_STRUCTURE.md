## 🔄 Maintenance Workflow

### Adding New Issue
```
1. Document in Troubleshooting Guide
   ├─→ Add tags (5 categories)
   ├─→ Add related issues/docs
   └─→ Add keywords

2. Update Quick Issue Finder
   └─→ Add error message entry

3. Update Documentation Index
   ├─→ Add to error message table
   ├─→ Add to symptom table
   └─→ Update tag lists

4. Log in Update Log
   └─→ Document what changed
```

### Updating Existing Doc
```
1. Make changes
2. Update "Last Updated" date
3. Add new tags if needed
4. Update cross-references
5. Update Documentation Index
6. Log in Update Log
```
