## Prize Pool Overview

- **Total Cash Prizes:** $250,000
- **Total AWS Credits:** $30,000
- **Additional:** AWS Builder swag
- **Total Winners:** 20 winning submissions across categories

## Winner Categories

### 1. Professional Track Award - Global Champion
**Number of Winners:** 2 winning submissions

**Selection Method:** Determined by community voting from the top 50 finalists

**Prizes per Winner:**
- $25,000 cash each
- $5,000 AWS credits each

**Total Value:** $50,000 cash + $10,000 AWS credits

---

### 2. Professional Track Award - Regional Champion
**Number of Winners:** 6 winning submissions (one per region)

**Selection Method:** Highest community-voted finalist from each AWS region:
- EMEA (Europe, Middle East, Africa)
- NAMER (North America)
- APJC (Asia Pacific, Japan, China)
- LATAM (Latin America)
- GCR (Greater China Region)
- ANZ (Australia, New Zealand)

**Prizes per Winner:**
- $15,000 cash each
- $1,500 AWS credits each

**Total Value:** $90,000 cash + $9,000 AWS credits

---

### 3. Innovation Award
**Number of Winners:** 10 winning submissions

**Selection Method:** Selected by panel of AWS Experts for:
- Breakthrough technical implementation
- Creative problem-solving

**Prizes per Winner:**
- $10,000 cash each
- $1,000 AWS credits each

**Total Value:** $100,000 cash + $10,000 AWS credits

---

### 4. Creative Track - Special Achievement Award
**Number of Winners:** 2 winning submissions

**Selection Method:** Selected by AWS expert panel for:
- Exceptional creativity
- Unique use cases
- Inspiring social impact

**Prizes per Winner:**
- $5,000 cash each
- $500 AWS credits each

**Total Value:** $10,000 cash + $1,000 AWS credits

---

## Additional Recognition

Winners receive:
- **Featured placement** at AWS re:Invent 2026
- **Recognition** across AWS channels
- **Opportunities** to connect with technical leaders
- **Showcase** at AWS Summits worldwide (May-September 2026)
