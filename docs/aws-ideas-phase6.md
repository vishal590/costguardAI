Your task is to build your application with the AWS Free Tier. You must also use Kiro for a portion of your application development.

No. Applications are judged on innovation, efficiency, and practical impact—not computational scale. Winning applications should be built entirely within Free Tier limits.



Do I need to document my AWS resource usage?
